# VLQ-1

**QEVARO's Romanian-language model project.**

**Status:** Active development  
**Public availability:** Targeting 2028  
**Previous public target:** Late 2026

VLQ-1 is a QEVARO language-model project focused on Romanian-language quality, reasoning, factual reliability, verification, calibration, and instruction following.

VLQ-1 was initially planned for public availability in late 2026. QEVARO revised the target to 2028 to allow additional model development, evaluation, and reliability work.

VLQ-1 is not publicly available yet.

No benchmark result, capability claim, or performance figure should be inferred from this repository unless it is explicitly identified as a completed and reviewed evaluation.

---

## Current focus

Development currently includes:

- Romanian-language quality
- reasoning consistency
- factual reliability
- verification
- uncertainty handling
- confidence calibration
- instruction following
- long-form consistency
- Romanian / English mixed-language behavior
- evaluation methodology

## Evaluation

VLQ-1 is intended to be evaluated across areas including:

- Romanian grammar and agreement
- Romanian diacritics
- natural Romanian phrasing
- formal and conversational Romanian
- instruction following
- factual question answering
- unsupported factual claims
- uncertainty acknowledgement
- confidence calibration
- long-form consistency
- Romanian / English code-switching

See [EVALUATION.md](EVALUATION.md).

No public benchmark scores are claimed at this stage.
