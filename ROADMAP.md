# VLQ-1 Roadmap

This roadmap describes the current public development direction for VLQ-1.

It is not a guarantee of specific release dates or capabilities.

## 2026

Current work includes:

- establishing public VLQ-1 development documentation
- defining Romanian-language evaluation areas
- documenting reliability and reasoning evaluation priorities
- establishing public release criteria
- continuing model development

## 2027

Planned development direction includes:

- continued model iteration
- expanded Romanian-language evaluation
- factual-reliability work
- reasoning-consistency evaluation
- calibration work
- verification work
- documentation of known limitations

## 2028

The current target period includes:

- expanded release evaluation
- publication of verified technical information
- release documentation
- public availability if release criteria are satisfied

## Timeline history

**Previous public availability target:** Late 2026  
**Current public availability target:** 2028

QEVARO revised the timeline to provide additional development and evaluation time.

The roadmap may change as development progresses.
