# VLQ-1 Public Changelog

This changelog records public development-documentation changes and major public project-status changes.

It does not represent internal model-training history.

## 2026-10-03

### Public development repository

- Created the public VLQ-1 repository under the QEVARO GitHub organization.
- Published the initial development model card.
- Published the initial evaluation framework.
- Published current development status.
- Added public roadmap and limitations documentation.
- Documented the current 2028 public availability target.

## 2026-10-02

### Release timeline revision

VLQ-1 was previously targeting public availability in late 2026.

The public availability target was revised to 2028 while QEVARO continues work on:

- Romanian-language quality
- factual reliability
- reasoning consistency
- verification
- confidence calibration
- uncertainty handling
- evaluation methodology
