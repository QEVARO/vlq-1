# VLQ-1 Release Criteria

VLQ-1 public availability is not determined solely by a calendar date.

The current target is 2028.

Before public release, QEVARO intends to review evidence across areas including:

- Romanian-language quality
- instruction following
- factual reliability
- reasoning consistency
- uncertainty handling
- confidence calibration
- known failure modes
- evaluation quality
- deployment readiness

## Evidence before claims

A capability should not be represented as established solely because it appears to work in isolated examples.

Public capability claims should be supported by appropriate evaluation evidence.

## Limitations

Known limitations should be documented alongside capabilities where relevant.

## Timeline

**Previous public availability target:** Late 2026

**Current public availability target:** 2028

The target may change as development progresses.
